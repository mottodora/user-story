# US-003: ホームページ・マップ選択機能

## ユーザーストーリー

**As a** ユーザーストーリーマッピングツールのユーザー  
**I want** 複数のマップを管理し、ホームページから選択できるようにしたい  
**So that** プロジェクトごとに異なるマップを作成・切り替えて利用できる

## 背景

初期のアプリケーションでは、単一のマップのみをサポートしていました。しかし、実際の利用シーンでは、複数のプロジェクトや異なるプロダクトのユーザーストーリーマップを管理したいというニーズがあります。

そこで、以下の機能を実装しました：
- ホームページでマップ一覧を表示
- 新規マップの作成
- マップの選択と個別画面への遷移
- サンプルマップとユーザーマップの分離表示

## 受け入れ基準

### ホームページ
- [ ] ホームページ（ルートパス `/`）が表示される
- [ ] ページタイトルと説明文が表示される
- [ ] 「新規マップを作成」ボタンが表示される

### マップ一覧表示
- [ ] サンプルマップとユーザーマップが分離して表示される
- [ ] 各マップカードには以下の情報が表示される：
  - マップ名
  - 作成日（日本語フォーマット）
  - サンプルマップにはバッジ表示
- [ ] マップが存在しない場合、空の状態メッセージが表示される

### 新規マップ作成
- [ ] 「新規マップを作成」ボタンをクリックすると、マップ名の入力を求められる
- [ ] マップ名を入力すると、新しいマップが作成される
- [ ] 作成後、自動的にそのマップの編集画面に遷移する

### マップ選択
- [ ] マップカードをクリックすると、そのマップの編集画面に遷移する
- [ ] URLは `/map/:mapId` の形式

### ルーティング
- [ ] `/` - ホームページ（マップ一覧）
- [ ] `/map/:mapId` - 個別マップ編集画面
- [ ] ブラウザの戻る/進むボタンが正しく動作する

### バックエンドAPI

#### GET /api/maps
- **処理**: 全マップの一覧を取得
- **レスポンス**: `StoryMap[]`

#### POST /api/maps
- **パラメータ**:
  - `name: string` - マップ名
- **処理**: 新しいマップを作成
- **レスポンス**: 作成されたマップオブジェクト

### データベーススキーマ

```prisma
model StoryMap {
  id         String   @id @default(uuid())
  name       String
  isSample   Boolean  @default(false)
  activities String?  @default("[]")
  stories    Story[]
  createdAt  DateTime @default(now())
  updatedAt  DateTime @updatedAt
}
```

### ルーティング設定

`src/App.tsx`での設定：
```tsx
<BrowserRouter>
  <Routes>
    <Route path="/" element={<HomePage />} />
    <Route path="/map/:mapId" element={<MapPage />} />
  </Routes>
</BrowserRouter>
```

## テストシナリオ

### 正常系
1. **初回アクセス**
   - ホームページにアクセス → タイトルと「新規マップを作成」ボタンが表示される
   - マップが存在しない場合、空の状態メッセージが表示される

2. **新規マップ作成**
   - 「新規マップを作成」をクリック → マップ名の入力を求められる
   - マップ名を入力（例: "新プロジェクト"）→ マップが作成され、編集画面に遷移

3. **マップ選択**
   - ホームページでマップカードをクリック → そのマップの編集画面に遷移
   - ブラウザの戻るボタンをクリック → ホームページに戻る

4. **複数マップの表示**
   - サンプルマップとユーザーマップが別々のセクションに表示される
   - 各マップカードに名前と作成日が表示される

### 異常系
1. **存在しないマップIDへのアクセス**
   - 存在しないマップIDのURLにアクセス → エラーメッセージまたはリダイレクト

2. **マップ作成のキャンセル**
   - 「新規マップを作成」をクリック → 名前入力をキャンセル → ホームページに留まる
